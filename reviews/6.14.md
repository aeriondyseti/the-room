# Review — 6.14 Percentage inside the bar (v0.7.1)

- **Trigger (Kevin):** "could we have the percentages be inside the progress bars?" Asked which style, he chose (a): htop/btop style.
- **Change:**
  - **The bar:** `shadedBar` draws each bar as cells. The filled part, round(pct/100 × cells), is reverse video in the state colour (green < 70%, amber 70–90%, red > 90%), so it survives NO_COLOR. The rest is a dim ░ track. The number (one decimal, plus a bold "!" from 70%) is centred over the bar. In the grids it's padded to its column's widest number, so decimals line up down each column (7.0% under 100.0%).
  - **Unchanged:** unknown is still "—" with no bar; stale and last-known are dim and colourless, with no "!".
  - **Fitting:** bars still go 10 → 8 cells → plain numbers to fit. The size is now monotonic in width, the largest size whose values fit: 6.12's "prefer inline caveats" rule could give a narrower terminal bigger bars, and the sweep test exposed that. Caveats go inline when they fit, else wrap.
  - **Other surfaces:** the compact lines, the agent rows and the left panel use the same bar.
- **Lean review (3 agents):** complete: true, 1 actionable (reported twice), fixed:
