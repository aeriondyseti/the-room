## Actionable — fixed
- **`room_read`'s "more available" hint pointed the wrong way** (conf 88).
  - Latest reads now say "older messages exist: `room_read after=<first-1-limit> limit=N`".
  - Cursor reads say "newer messages exist: `after=<last>`".
  - Tested.

## Tech debt worked immediately (identity integrity and process hygiene)
- **A rebind could take over any live name** (conf 55, reported twice). A rebind now only moves a
  same-harness name whose session is not online; anything else is `rebind_conflict` with a hint. Tested.
- **`room mcp` never exited after its host closed stdin** (conf 65, reported twice). It now closes the room
  connection and exits on stdin end or close.
- **Concurrent first tool calls opened duplicate connections** (conf 50). One shared connection attempt
  now serves them.
- **Codex without `_meta` could be attributed to an ancestor Claude** (conf 45). The ancestor walk now stops
  at an intermediate `codex`/`agy`/`gemini` process. Tested.
- **Process-table failures were cached as "no session"** (conf 45). They're no longer cached, and they
  report a retryable error. Tested.
- **Unverified ancestors were accepted** (conf 35). An unverifiable start time is accepted only for the
  direct parent.
- **`room_send`'s `idempotentHint`** is now false; it's only idempotent when `client_message_id` is reused.

## Deferred

  are not `ROOM_*` tunables.
