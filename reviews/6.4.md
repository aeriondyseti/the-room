# Review — 6.4 Slash-command discovery in the TUI (v0.2.1)

- **Trigger:** Kevin, in the room: "hitting / should show a listing of commands, filtered by character as I type."
- **Change:**
  - `COMMAND_CATALOGUE` in composer.ts is now the single source of commands (name, argument hint, description).
    Parsing, `/help` and the new suggestion list all derive from it (Astra's scope note), so they can't drift.
  - Typing `/` plus a partial name lists matching commands above the composer: bounded to 6 rows plus "+N more",
    with the highlight kept in view.
  - Tab completes the highlighted command (adding a trailing space if it takes arguments). ↑/↓ move the highlight.
    Enter runs an exact name as typed. For a partial name, Enter picks the highlighted command, running it at once
    if it takes no arguments.
  - The list hides as soon as arguments start. `@name` Tab completion and ↑/↓ history are unchanged outside the
    list. `/restart`'s second-Enter confirmation is preserved.
  - The composer's height includes the list, so the conversation viewport stays line-accurate.
- **Tests:** three composer tests (listing and filtering from the catalogue; Tab/↑/↓ vs @name and history;
  partial + Enter, including the /restart confirmation).
- **Review:** small UI change, cross-reviewed by Astra (who offered). The lean workflow was skipped per ADR-0007's
  budget.
