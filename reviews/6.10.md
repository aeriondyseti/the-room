# Review — 6.10 Organised top bar (Kevin's mockup, top bar only) (v0.6.0)

- **Trigger (Kevin, room):**
  - "Look at D:\sable\notes\the-room-ui-mockup.md for a design request on how the top bar can be made to look more organized."
  - His answers: colours option **c** (the mockup's state colours for the bars, keep per-agent name colours); **top bar only for now**.
  - During the sprint: "Can we also align the reset timers? As a rule of thumb, aligning like pieces of information would be preferred."
  - And: "you can hide login unverified part; that's almost always going to be true".
- **Change:**
  - **AGENTS:** one aligned row per agent: dot, name, state, ctx, model, branch.
    - Only the state word is loud: busy is bold, idle plain.
    - Model and branch are quiet.
    - The dot follows activity: green idle, amber busy or approval, grey otherwise.
    - Detail is shed to fit: bars first, then model, then branch. More than 6 agents → "+N more · /who".
  - **BUDGETS:** a grid naming 5h and weekly once, with one row per limit (Claude, Fable, Codex).
    - Like pieces sit in their own measured columns: value, reset time, caveat.
    - Percentages are right-aligned to each column's widest number.
    - A missing value is "—", never 0.
    - Caveats (stale, last known, via statusline) sit on the account's row, or wrap onto a continuation row; they're never cut. "Login unverified" is hidden (it's still recorded in the data).
  - **Bar colours:** by state, in both layouts: green < 70%, amber 70–90%, red > 90%, plus a bold "!" from 70% (NO_COLOR keeps it).
  - **Density:** `/compact [on|off]` and Ctrl+T switch it explicitly (never automatically), remembered in `.room/tui.json`.
  - **Fallbacks:** the grid yields to the old wrapping chip and metric lines when it's too narrow (measured), too short (the conversation keeps ≥ 10 rows, counting the persistent banner and notice rows), or while any overlay is open.
  - **Help:** it now pages like `/detail` (PgDn). The key column is measured, so keys no longer run into their descriptions.
- **Lean review (3 agents, ADR-0007):** complete: true, 1 actionable (reported twice), fixed:
  - A 100.0% reading (a limit that was hit) broke decimal alignment, because the pad was a fixed 4 characters. Each column now pads to its widest number. Regression test added.
- **Tech-debt findings, also fixed:**
  - The README misdescribed the fallback and still showed `n/a` for Codex 5h.
  - The height guard now counts the persistent banner and the left-layout notice. Transient rows (feedback, a multi-line draft, suggestions) are deliberately not counted, so the grid doesn't flicker while typing → TD-0027.

  - grid alignment of values, resets, caveats and right-aligned numbers, including 100% vs 7%;
  - loud and quiet weights, and the shedding order;
  - overflow, "last known", "—", unavailable rows, caveat wrapping, and the null fallback;
  - the activity dot and the colour thresholds;
  - `/compact`, Ctrl+T and persistence;
  - the height and overlay guards;
  - help paging and the measured key column.
