  (`gpt-6-astra`, `claude-opus-5-5`), session working directories, and Git branches. Claude's current

- Tests cover same-cwd cache reuse, unborn repositories, staged/modified overlap, untracked files,

- Full suite: 274 passing after the review fixes. New provider tests: 6 passing independently.

## Bounds and limitations

- `ROOM_WORKSPACE_READ_BYTES` (2 MiB) bounds transcript head plus tail reads per sample;
  metadata entirely in the omitted middle cannot be reported. Unknown model/cwd remains null.
- `ROOM_WORKSPACE_SCAN_ENTRIES` (10,000) and `ROOM_WORKSPACE_TIMEOUT_MS` (3,000) bound discovery
  effort and the caller's observation wait. Filesystem operations already submitted to the OS may
  finish later; the provider retains that session's pending operation rather than starting duplicate
  reads on every monitor tick.
- Git uses argv-only commands, clears inherited repository-local Git overrides, disables optional
  locks, and never refreshes or writes the index. `ROOM_WORKSPACE_GIT_MAX_BYTES` (2 MiB) bounds each
  response and `ROOM_WORKSPACE_GIT_CACHE_MS` (15 seconds) caches by cwd. Oversized/error responses
  are unavailable, never a partial clean result. Dirty is a unique porcelain-entry count; staged and
  modified can overlap. No upstream means ahead/behind are null, not zero.
- Temporary fixture repositories remain under the OS temp directory with `vpfix-*` prefixes;
  they contain only test data. No fixture harness processes were launched.
