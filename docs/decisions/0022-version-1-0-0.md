# The project is at 1.0.0

## Context and Problem Statement

Kevin's rule is that 0.x means still being built and 1.0.0 means in use. The latest tag was `v0.9.0`. On 2026-11-09
he said the project was ready for 1.0.0, since other repos of his had run rooms on it, and that he was not cutting
it then. On 2026-11-13 the project was renamed to agent-roundtable (ADR-0021) and its repository made public.

## Decision Outcome

- The next release is `1.0.0`, cut by the release command on Kevin's word. It is the first release under the name
  agent-roundtable.
- From 1.0.0 the public API named in `docs/reference/design.md` is covered by semver: a breaking change to it is a
  major version.

### Consequences

The rename of the CLI, the MCP tools, the settings and the state directory is in 1.0.0, not after it, so 1.x starts
with the names in ADR-0021. The cut-over in ADR-0018 (proposed) named `v0.10.0` as the next release; this record
replaces that number.

## More Information

Kevin, 2026-11-13: "cut 1.0.0 through the release command." It is cut with `--version 1.0.0`: before 1.0.0 the release command
reads a breaking change in `[Unreleased]` as a minor version.
